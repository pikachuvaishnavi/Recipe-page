# Recipe Page

This project is a responsive recipe page built as part of a Frontend Mentor challenge. I created a clean and polished layout for a simple omelette recipe and styled it to closely match the provided design.

## What I built

- Structured the recipe page using semantic HTML with sections for the header, preparation details, ingredients, instructions, and nutrition.
- Added the omelette image, recipe title, short description, and a highlighted preparation card.
- Styled the page with a white card layout, rounded corners, custom colors, and readable typography.
- Designed the ingredient and instruction lists with custom markers and spacing to match the recipe design.
- Built a nutrition section with a clean table-like layout and added the footer attribution.
- Applied responsive styling so the layout works well on smaller screens as well.

## Technologies used

- HTML5
- CSS3
- Responsive web design

## What I learned

- How to structure content with semantic HTML
- How to style a complete page using CSS
- How to make a layout responsive for mobile devices
- How to match a design more closely through spacing, colors, and typography
